# DocumentManagement (тестовое)

Веб-приложение для хранения, просмотра и добавления версий документов с регистрационными карточками. Реализованы функции загрузки новых документов, добавления версий, снятия с учёта и просмотра сведений.

## Стек

**Backend**
  - Java 8
  - Spring Core
  - Spring MVC
  - JDBC (Hibernate)
  - Apache Tomcat (сервер)
  - PostgreSQL (БД)

**Frontend**
  - Vue.js
  - Vite
  - Vue Router
  - Pinia
  - Bootstrap
  - Axios

Управление зависимостями: Maven (backend), npm (frontend)

## Требования к окружению

- Java 8 или выше
- Node.js
- PostgreSQL
- Apache Tomcat

## Сборка версия 1
- **Backend**
    ```sh
    cd backend
    mvn clean package
    ```

    Скопировать файл "ROOT.war" из папки target

    Вставить файл в папку "...\apache-tomcat-<версия>\webapps"
    
    Зайти в папку "...\apache-tomcat-<версия>\bin"
    ```sh
    .\startup.bat
    ```

- **Frontend**
    ```sh
    cd frontend
    npm install
    npm run dev
    ```

## Сборка 2 (через IDE)

## Приложение должно обеспечивать следующие операции

**«Загрузка нового документа»**

При загрузке открывается форма:
- пользователю предлагается выбрать файл для загрузки (кнопка)
- заполнить следующие поля
1. Название документа
2. Входящий номер документа
3. Дата поступления (заполняется автоматически readonly) - устанавливается в текущую дату загрузки документа.
При загрузке нового документа автоматически создается его версия с номером «1».

**«Загрузка новой версии документа»**

Пользователь выбирает документ и нажимает «Загрузить новую версию». Пользователю предлагается выбрать файл для загрузки (кнопка). После загрузки создается новая запись в таблице версий с номером версии «+1» от имеющейся версии документа.

**«Просмотр документа»**

Возможность скачать файл на форме содержащей сведения:
- Название документа
- Входящий номер документа
- Дата поступления

**«Снять документ с учета»**

Документ остается в базе данных, однако перед этим пользователю необходимо заполнить поле: «Исходящий номер»
При этом поле Дата снятия с учета заполняется автоматически.
